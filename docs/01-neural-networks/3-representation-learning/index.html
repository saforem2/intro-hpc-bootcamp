The previous notebooks trained a classifier that did OK — when we had lots of labeled data. But labels are expensive: someone has to annotate every image. So here’s the question that drives this page:

What if we have piles of unlabeled data but only a handful of labels?

The answer is representation learning: use the unlabeled data to teach the network a good representation of images (a feature space where similar things land near each other), then attach a small classifier on top. The headline technique here is contrastive learning (the idea behind SimCLR): show the network two randomly augmented views of the same image and train it to pull their representations together while pushing apart the representations of different images — all without a single label.

This page has two parts:

  1. A miniature you can actually run (just below) — a tiny contrastive learner on Fashion-MNIST that trains on a laptop in under a minute. We’ll watch its loss go down and measure how good the learned features are. The result is an honest and slightly surprising one — it sets up the punchline of the whole course.
  2. The real, cluster-scale version (further down) — the original CIFAR-10 + multi-GPU SimCLR code, kept as a reference for how this is done for real on a supercomputer.

🏃 A contrastive learner you can run right now

Everything in this section uses only torch / numpy / matplotlib, downloads one small dataset, and runs on CPU. Let’s set the stage:

def take(dataset, n, seed):
    """Grab a fixed random subset as tensors (X, y)."""
    idx = torch.randperm(len(dataset), generator=torch.Generator().manual_seed(seed))[:n]
    X = torch.stack([dataset[i][0] for i in idx])
    y = torch.tensor([dataset[i][1] for i in idx])
    return X, y

# A pool of UNLABELED images for contrastive pretraining, and a labeled test set.
X_unlabeled, _ = take(_train, 6000, seed=1)
X_test, y_test = take(_test, 2000, seed=2)

The encoder. A small CNN that maps a 28×28 image to a 64-dimensional representation vector. This is the thing we’re trying to teach.

class Encoder(nn.Module):
    """Tiny CNN: image -> 64-d representation."""
    def __init__(self, dim=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(1, 32, 3, stride=2, padding=1), nn.ReLU(),   # 28 -> 14
            nn.Conv2d(32, 64, 3, stride=2, padding=1), nn.ReLU(),  # 14 -> 7
            nn.AdaptiveAvgPool2d(1), nn.Flatten(),
            nn.Linear(64, dim),
        )

    def forward(self, x):
        return self.net(x)

The contrastive objective (NT-Xent). For a batch of images we make two augmented views of each, encode them, and ask: for every view, is its positive partner (the other view of the same image) closer than all the other images in the batch? That’s exactly a classification problem the model can be trained on — no labels required.

# Two random "views" of an image: crop + flip. Same picture, different look.
augment = T.Compose([
    T.RandomResizedCrop(28, scale=(0.5, 1.0), antialias=True),
    T.RandomHorizontalFlip(),
])

def nt_xent(z1, z2, temperature=0.2):
    """Normalized temperature-scaled cross-entropy (the SimCLR loss)."""
    z = F.normalize(torch.cat([z1, z2], dim=0), dim=1)   # (2N, d), unit vectors
    sim = z @ z.t() / temperature                        # cosine similarities
    sim.fill_diagonal_(-9e15)                            # a view can't match itself
    n = z1.shape[0]
    targets = (torch.arange(2 * n) + n) % (2 * n)        # positive partner index
    return F.cross_entropy(sim, targets)

Train it — 300 steps on the unlabeled pool. Watch the loss fall: the model is genuinely learning to recognize “same image, different view.”

encoder = Encoder()
projector = nn.Sequential(nn.Linear(64, 64), nn.ReLU(), nn.Linear(64, 32))
opt = torch.optim.Adam(list(encoder.parameters()) + list(projector.parameters()), lr=1e-3)

_t0 = time.time()
loss_curve = []
for step in range(300):
    xb = X_unlabeled[torch.randint(0, len(X_unlabeled), (256,))]
    z1 = projector(encoder(augment(xb)))
    z2 = projector(encoder(augment(xb)))
    loss = nt_xent(z1, z2)
    opt.zero_grad(); loss.backward(); opt.step()
    if step % 50 == 0:
        loss_curve.append((step, round(loss.item(), 3)))
print("contrastive loss:", loss_curve)
print(f"trained in {time.time() - _t0:.0f}s on CPU  (labels used: 0)")

The loss drops from ~6 to ~4 — the contrastive task is being solved. So how good are the features? Let’s measure honestly, using labels only to evaluate (never to train the encoder). We compare three feature spaces with a simple 5-nearest-neighbor classifier:

Important🤔 Wait — the fancy method lost?

On this tiny, CPU-scale setup the honest result is surprising: our contrastively-trained features are barely better than a randomly initialized encoder, and raw pixels win outright. That is not a bug — it’s the real lesson.

Fashion-MNIST is small and low-resolution, so raw pixels are already fairly separable, and 300 steps of contrastive training on 6,000 tiny images simply isn’t enough signal to learn features that beat them. Self-supervised methods like SimCLR only pull ahead when:

  • the data is high-dimensional and complex (big natural images, genomes, audio), where raw inputs are not linearly separable;
  • you pretrain on huge unlabeled corpora for many epochs with large batches (SimCLR used batch sizes of 4096+).

Those three requirements — big data, big batches, long training — are exactly why contrastive pretraining is run on supercomputers. This little laptop demo is honest about its own limits, and in doing so it motivates the rest of the course: [01.4] Distributed Training and [02.1] the Perlmutter lab are how you get to the scale where methods like this actually shine.

🚀 Now with a real GPU: the payoff

So let’s actually give it the scale. We ran the same recipe — contrastive pretrain, then linear-probe with few labels — on a single NVIDIA A100 (one Polaris node at ALCF), but with the knobs the laptop couldn’t afford: the harder CIFAR-10 (color images, where raw pixels are not linearly separable), a batch size of 1024, 2,000 steps, and the full 50,000-image unlabeled pool. The whole thing finished in ~51 seconds on the GPU.

This time the story flips completely — the learned representation wins at every label budget, and by a wide margin exactly where it matters most (few labels).

def run_experiment():
    """Full contrastive-pretrain + low-label linear-probe sweep on CIFAR-10.
    Only invoked when a CUDA GPU is available (it's too heavy for a CPU build)."""
    import time
    import torch.nn as nn
    import torch.nn.functional as F
    import torchvision
    from torchvision import transforms as T

    dev = "cuda"
    t0 = time.time()
    torch.manual_seed(0); np.random.seed(0)
    tfm = T.Compose([T.ToTensor()])
    tr = torchvision.datasets.CIFAR10("data", train=True, download=True, transform=tfm)
    te = torchvision.datasets.CIFAR10("data", train=False, download=True, transform=tfm)

    def take(ds, n, seed):
        idx = torch.randperm(len(ds), generator=torch.Generator().manual_seed(seed))[:n]
        return torch.stack([ds[i][0] for i in idx]), torch.tensor([ds[i][1] for i in idx])

    class Encoder(nn.Module):
        def __init__(s, dim=256):
            super().__init__()
            s.net = nn.Sequential(
                nn.Conv2d(3, 64, 3, 2, 1), nn.BatchNorm2d(64), nn.ReLU(),
                nn.Conv2d(64, 128, 3, 2, 1), nn.BatchNorm2d(128), nn.ReLU(),
                nn.Conv2d(128, 256, 3, 2, 1), nn.BatchNorm2d(256), nn.ReLU(),
                nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(256, dim))
        def forward(s, x): return s.net(x)

    aug = T.Compose([T.RandomResizedCrop(32, scale=(0.3, 1.0), antialias=True),
                     T.RandomHorizontalFlip(),
                     T.RandomApply([T.ColorJitter(0.4, 0.4, 0.4, 0.1)], p=0.8),
                     T.RandomGrayscale(p=0.2)])

    def nt_xent(z1, z2, temp=0.2):
        z = F.normalize(torch.cat([z1, z2], 0), dim=1); n = z1.shape[0]
        sim = z @ z.t() / temp; sim.fill_diagonal_(-9e15)
        return F.cross_entropy(sim, (torch.arange(2 * n, device=z.device) + n) % (2 * n))

    Xun, _ = take(tr, 50000, 1); Xun = Xun.to(dev)
    Xte, yte = take(te, 4000, 2); Xte = Xte.to(dev); yte = yte.to(dev)
    enc = Encoder().to(dev)
    proj = nn.Sequential(nn.Linear(256, 256), nn.ReLU(), nn.Linear(256, 128)).to(dev)
    opt = torch.optim.Adam(list(enc.parameters()) + list(proj.parameters()), lr=1e-3)
    for _ in range(2000):
        xb = Xun[torch.randint(0, len(Xun), (1024,), device=dev)]
        loss = nt_xent(proj(enc(aug(xb))), proj(enc(aug(xb))))
        opt.zero_grad(); loss.backward(); opt.step()

    def probe(Xtr, ytr):
        enc.eval()
        with torch.no_grad(): Ztr, Zte = enc(Xtr.to(dev)), enc(Xte)
        clf = nn.Linear(256, 10).to(dev); o = torch.optim.Adam(clf.parameters(), lr=1e-2)
        yt = ytr.to(dev)
        for _ in range(200):
            o.zero_grad(); F.cross_entropy(clf(Ztr), yt).backward(); o.step()
        with torch.no_grad(): return (clf(Zte).argmax(1) == yte).float().mean().item()

    def scratch(Xtr, ytr, ep=60, bs=64):
        e = Encoder().to(dev); h = nn.Linear(256, 10).to(dev)
        o = torch.optim.Adam(list(e.parameters()) + list(h.parameters()), lr=1e-3)
        Xt, yt = Xtr.to(dev), ytr.to(dev); e.train()
        for _ in range(ep):
            p = torch.randperm(len(Xt), device=dev)
            for i in range(0, len(Xt), bs):
                b = p[i:i + bs]
                o.zero_grad(); F.cross_entropy(h(e(Xt[b])), yt[b]).backward(); o.step()
        e.eval()
        with torch.no_grad(): return (h(e(Xte)).argmax(1) == yte).float().mean().item()

    rows = []
    for n in [100, 250, 500, 1000, 5000]:
        Xtr, ytr = take(tr, n, 3)
        rows.append([n, round(scratch(Xtr, ytr), 3), round(probe(Xtr, ytr), 3)])
    return {"device": "cuda", "gpu": torch.cuda.get_device_name(0), "dataset": "CIFAR-10",
            "batch": 1024, "steps": 2000, "pool": 50000, "rows": rows,
            "total_s": round(time.time() - t0, 1)}

from torch import nn

class Downsampler(nn.Module):
    def __init__(self, in_channels, out_channels, stride=2):
        super(Downsampler, self).__init__()
        self.norm = nn.InstanceNorm2d(in_channels)
        self.downsample = nn.Conv2d(
            in_channels=in_channels, 
            out_channels=out_channels,
            kernel_size = stride,
            stride = stride,
        )

    def forward(self, inputs):
        return self.downsample(self.norm(inputs))


class ConvNextBlock(nn.Module):
    def __init__(self, in_channels):
        super(ConvNextBlock, self).__init__()
        # Depthwise, seperable convolution with a large number of output filters:
        self.conv1 = nn.Conv2d(
            in_channels=in_channels,
            out_channels=in_channels,
            groups=in_channels,
            kernel_size=(7, 7),
            padding='same'
        )
        self.norm = nn.InstanceNorm2d(in_channels)
        self.conv2 = nn.Conv2d(
            in_channels=in_channels,
            out_channels=4*in_channels,
            kernel_size=1
        )
        self.conv3 = nn.Conv2d(
            in_channels=4*in_channels,
            out_channels=in_channels,
            kernel_size=1
        )


    def forward(self, inputs):
        # x = self.conv1(inputs)
        # The normalization layer:
        # x = self.norm(x)
        # x = self.conv2(x)
        # The non-linear activation layer:
        # x = torch.nn.functional.gelu(x)
        # x = self.conv3(x)
        # This makes it a residual network:
        return inputs + self.conv3(
            torch.nn.functional.gelu(
                self.conv2(
                    self.norm(
                        self.conv1(inputs)
                    )
                )
            )
        )


class Classifier(nn.Module):


    def __init__(self, n_initial_filters, n_stages, blocks_per_stage, n_outputs):
        super(Classifier, self).__init__()
        # This is a downsampling convolution that will produce patches of output.
        # This is similar to what vision transformers do to tokenize the images.
        self.stem = nn.Conv2d(in_channels=3,
                                    out_channels=n_initial_filters,
                                    kernel_size=1,
                                    stride=1)
        self.norm1 = nn.InstanceNorm2d(n_initial_filters)

        current_n_filters = n_initial_filters
        self.layers = nn.Sequential()
        for n_blocks in range(n_stages):
            # Add a convnext block series:
            for _ in range(blocks_per_stage):
                self.layers.append(ConvNextBlock(in_channels=current_n_filters))
            # Add a downsampling layer:
            self.layers.append(Downsampler(in_channels=current_n_filters, out_channels=2*current_n_filters))
            # Double the number of filters:
            current_n_filters = 2*current_n_filters
        self.head = nn.Sequential(
            nn.Flatten(),
            nn.LayerNorm(current_n_filters),
            nn.Linear(current_n_filters, n_outputs)
        )

    def forward(self, inputs):
        x = self.stem(inputs)
        # Apply a normalization after the initial patching:
        x = self.norm1(x)
        # Apply the main chunk of the network:
        x = self.layers(x)
        # Normalize and readout:
        x = nn.functional.avg_pool2d(x, x.shape[2:])
        x = self.head(x)
        return x

def contrastive_loss(first_images, second_images, rank, world_size = 1, temperature=0.1):
        # Each image is represented with k parameters,
        # Assume the batch size is N, so the
        # inputs have shape (N, k)

        # These are pre-distributed shapes:
        N = first_images.shape[0]
        k = first_images.shape[1]


        first_images = first_images / torch.norm(first_images,dim=1).reshape((-1,1))
        second_images = second_images / torch.norm(second_images,dim=1).reshape((-1,1))

        # Take the two tuples, and concatenate them.
        # Then, reshape into Y = (1, 2N, k) and Z = (2N, 1, k)

        c = torch.concat([first_images, second_images], dim=0)

        # Gather all the c up if the world size > 1:
        if world_size > 1:
            gathered_c = torch.distributed.all_gather(tensor=c)
            gathered_c = gathered_c.reshape((-1, first_images.shape[-1]))
        else:
            gathered_c = c

        # Each rank computes only a slice of the global loss matrix, or
        # the memory usage gets out of control.

        # We calculate the dot product between the local and global tensors:
        local_reps = c.reshape((c.shape[0], 1, c.shape[1]))
        all_reps   = gathered_c.reshape((1, gathered_c.shape[0], gathered_c.shape[1]))


        # Assume we have n images per rank, for N global images with N = n * world_size
        # Compute the product of these tensors, which gives shape
        # (2n, 2N, k)
        mat =  local_reps*all_reps

        # We need to compute the function (sim(x,y)) for each element in the 2N sequent.
        # Since the are normalized, we're computing x^T . Y / (||x||*||y||),
        # but the norms are equal to 1.
        # So, summing the matrix over the dim = 0 and dim = 1 computes this for each pair.

        sim = torch.sum(mat, dim=-1) / temperature



        # Now, sim is of shape [2*n, 2*N]

        # This yields a symmetric matrix, diagonal entries equal 1.  Off diagonal are symmetrics and < 1.

        # sim = torch.exp(sim / temperature)
        # Now, for every entry i in C (concat of both batches), the sum of sim[i] - sim[i][i] is the denominator

        device = sim.device

        # Since we have a non-symmetric matrix, need to build a non-symmetric index:
        positive = torch.zeros(sim.shape, device=device)

        # We concatenated all the local examples, and compute symmetric positive pairs
        # So for the first N entries, the index of the positive pair is i + N  (locally)
        # For the second N entries, the index of the positive pair is i - N (locally)
        # with a distributed run, we've squashed all the similarity scores together.
        # to a shape of [2*N, 2*N*Size]
        # Each 2*N by 2*N block is the local positive indexes, all others are negative.
        # That means that the index is shifted by global_rank*2*N

        access_index_x = torch.arange(2*N)
        # For the first N, the y-index is equal to x + 2*N
        # For the second N
        access_index_y = torch.arange(2*N)
        # Shift by +/- N:
        access_index_y[0:N] = access_index_y[0:N] + N
        access_index_y[N:]  = access_index_y[N:] - N

        access_index_y +=  rank * 2*N

        # console.log("access_index_y: ", access_index_y, flush=True)

        positive[access_index_x, access_index_y] = 1

        # For the negative, we invert the positive and have to 0 out the self-index entries
        negative = 1 - positive

        # THESE WORK IF IT'S NOT DISTRIBUTED
        # positive = torch.tile(torch.eye(N, device=device), (2,2))
        # # Unsure if this line is needed?
        # positive = positive - torch.eye(2*N, device=device)
        #
        # negative = - (torch.eye(2*N, device=device) - 1)

        with torch.no_grad():
            # Here, we can compute the top-k metrics for this batch, since we have the global state:
            # We want the top 5 entries but the self-sim is obviously perfect.
            # So take the top 6 and reject the first.
            topk = torch.topk(sim, k=6, dim=-1, sorted=True)

            # Top 1 is just an equality check:
            top1_acc = topk.indices[:,1] == access_index_y.to(topk.indices.device)
            top1_acc = torch.mean(top1_acc.to(torch.float))
          
            # Top 5 is a little more complicated:
            # Compute the index distance to the correct index, abs value:
            top5_acc_dist = torch.abs(topk.indices[:,1:] - access_index_y.to(topk.indices.device).reshape(-1,1))
            # Get the minumum value, and see if it is less than 5:
            min_values, _ = torch.min(top5_acc_dist, dim=-1)
            top5_acc =  min_values < 5.
            # Average over the batch dimension:
            top5_acc = torch.mean(top5_acc.to(torch.float))


        negative_examples = sim * negative
        positive_examples = sim * positive

        # Now, positive/negative examples is the temperature normalized similarity.
        # we need to sum across the whole batch dimension to compute it per-example:


        # Compute the alignment, summed over the entire global batch:
        alignment = torch.sum(positive_examples, dim=-1)

        # Compute the exp, which we'll eventually sum and log:
        exp = torch.sum(torch.exp(negative_examples), dim=-1)

        # console.log("Alignment: ", alignment, flush=True)
        # console.log("exp: ",       exp, flush=True)


        # And compute the logsumexp of the negative examples:
        log_sum_exp = torch.log(exp )


        # Additionally, we can compute the "floor" of the loss at this batch size:
        # floor = torch.log(1.*N) - 1.

        loss_metrics = {
            "alignment"   : torch.mean(alignment),
            "log_sum_exp" : torch.mean(log_sum_exp),
            "top1"        : top1_acc,
            "top5"        : top5_acc,
            # "floor"       : floor,
        }

        loss = torch.mean( - alignment + log_sum_exp)
        return loss, loss_metrics
def train_one_epoch(dataloader, t1, t2, model, head, loss_fn, optimizer, rank, size, progress_bar):
    model.train()
    head.train()
    for (batch, (X, _)) in enumerate(dataloader):
        # forward pass
        X1 = t1(X); X2 = t2(X)
        pred1 = head(model(X1))
        pred2 = head(model(X2))
        loss, metrics = loss_fn(pred1, pred2, rank, size)

        # console.log(metrics)
        
        # backward pass calculates gradients
        loss.backward()
        
        # take one step with these gradients
        optimizer.step()
        
        # resets the gradients 
        optimizer.zero_grad()

        # progress_bar.refresh()
        cpu_metrics = { key : f"{metrics[key].detach().cpu().numpy():.2f}" for key in metrics.keys()}
        cpu_metrics["loss"] = f"{loss.detach().cpu().numpy():.2f}"
        progress_bar.update()
        progress_bar.set_postfix(cpu_metrics)
        # progress_bar.description = f"Train loss: {loss.cpu():.2f} top5: {metrics['top5'].cpu():.2f}"
        # break
def validate_one_epoch(dataloader, t1, t2, model, head, loss_fn, rank, size, progress_bar):
    # Validation must NOT update the weights: put everything in eval mode and
    # disable gradients. (This function used to call .backward()/optimizer.step()
    # — that would *train* on the validation set, which defeats the purpose of a
    # held-out set. Validation only measures; it never learns.)
    model.eval()
    head.eval()
    n = 0.
    sum_metrics = None
    with torch.no_grad():
        for (batch, (X, _)) in enumerate(dataloader):
            # forward pass only
            X1 = t1(X); X2 = t2(X)
            pred1 = head(model(X1))
            pred2 = head(model(X2))
            loss, metrics = loss_fn(pred1, pred2, rank, size)

            cpu_metrics = { key : metrics[key].detach().cpu().numpy() for key in metrics.keys()}
            if sum_metrics is None:
                sum_metrics = cpu_metrics
            else:
                for key in sum_metrics.keys():
                    sum_metrics[key] += cpu_metrics[key]
            progress_bar.update()
            n += 1.

    for key in sum_metrics:
        sum_metrics[key] = sum_metrics[key] / n
    return sum_metrics
optimizer = torch.optim.AdamW(list(model.parameters()) + list(head.parameters()), lr=0.001)

def evaluate(dataloader, model, head, loss_fn, val_bar):
    # Set the model to evaluation mode - some NN pieces behave differently during training
    # Unnecessary in this situation but added for best practices
    model.eval()
    size = len(dataloader)
    num_batches = len(dataloader)
    loss, correct = 0, 0

    # We can save computation and memory by not calculating gradients here - we aren't optimizing 
    with torch.no_grad():
        # loop over all of the batches
        for X, y in dataloader:

            pred = head(model(X))
            loss += loss_fn(pred, y).item()
            # how many are correct in this batch? Tracking for accuracy 
            correct += (pred.argmax(1) == y).type(torch.float).sum().item()
            val_bar.update()
            
    loss /= num_batches
    correct /= (size*batch_size)
    
    accuracy = 100*correct
    return accuracy, loss

The previous notebooks trained a classifier that did OK — *when we had lots of
labeled data.* But labels are expensive: someone has to annotate every image. So
here's the question that drives this page:

> **What if we have piles of *unlabeled* data but only a handful of labels?**

The answer is **representation learning**: use the unlabeled data to teach the
network a good *representation* of images (a feature space where similar things
land near each other), *then* attach a small classifier on top. The headline
technique here is **contrastive learning** (the idea behind
[SimCLR](https://arxiv.org/abs/2002.05709)): show the network two randomly
augmented views of the same image and train it to pull their representations
together while pushing apart the representations of *different* images — all
without a single label.

This page has two parts:

1. **A miniature you can actually run** (just below) — a tiny contrastive learner
   on Fashion-MNIST that trains on a laptop in under a minute. We'll watch its
   loss go down and *measure* how good the learned features are. The result is an
   honest and slightly surprising one — it sets up the punchline of the whole
   course.
2. **The real, cluster-scale version** (further down) — the original CIFAR-10 +
   multi-GPU SimCLR code, kept as a reference for how this is done for real on a
   supercomputer.

## 🏃 A contrastive learner you can run right now {#sec-mini}

Everything in this section uses only `torch` / `numpy` / `matplotlib`, downloads
one small dataset, and runs on CPU. Let's set the stage:

```{python}
import os
import time
import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F
import torchvision

torch.manual_seed(0)
np.random.seed(0)

# Fashion-MNIST: small, downloads reliably, and (importantly) *harder* than digits.
_tfm = T.Compose([T.ToTensor()])
_train = torchvision.datasets.FashionMNIST(root="data", train=True, download=True, transform=_tfm)

def take(dataset, n, seed):
    """Grab a fixed random subset as tensors (X, y)."""
    idx = torch.randperm(len(dataset), generator=torch.Generator().manual_seed(seed))[:n]
    X = torch.stack([dataset[i][0] for i in idx])
    y = torch.tensor([dataset[i][1] for i in idx])
    return X, y

# A pool of UNLABELED images for contrastive pretraining, and a labeled test set.
X_unlabeled, _ = take(_train, 6000, seed=1)
X_test, y_test = take(_test, 2000, seed=2)
print(f"unlabeled pool: {tuple(X_unlabeled.shape)}   test set: {tuple(X_test.shape)}")
```

**The encoder.** A small CNN that maps a 28×28 image to a 64-dimensional
*representation* vector. This is the thing we're trying to teach.

```{python}
class Encoder(nn.Module):
    """Tiny CNN: image -> 64-d representation."""
    def __init__(self, dim=64):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(1, 32, 3, stride=2, padding=1), nn.ReLU(),   # 28 -> 14
            nn.Conv2d(32, 64, 3, stride=2, padding=1), nn.ReLU(),  # 14 -> 7
            nn.AdaptiveAvgPool2d(1), nn.Flatten(),
            nn.Linear(64, dim),
        )

    def forward(self, x):
        return self.net(x)
```

**The contrastive objective (NT-Xent).** For a batch of images we make two
augmented views of each, encode them, and ask: for every view, is its
*positive partner* (the other view of the same image) closer than all the other
images in the batch? That's exactly a classification problem the model can be
trained on — no labels required.

```{python}
# Two random "views" of an image: crop + flip. Same picture, different look.
augment = T.Compose([
    T.RandomResizedCrop(28, scale=(0.5, 1.0), antialias=True),
    T.RandomHorizontalFlip(),
])

def nt_xent(z1, z2, temperature=0.2):
    """Normalized temperature-scaled cross-entropy (the SimCLR loss)."""
    z = F.normalize(torch.cat([z1, z2], dim=0), dim=1)   # (2N, d), unit vectors
    sim = z @ z.t() / temperature                        # cosine similarities
    sim.fill_diagonal_(-9e15)                            # a view can't match itself
    n = z1.shape[0]
    targets = (torch.arange(2 * n) + n) % (2 * n)        # positive partner index
    return F.cross_entropy(sim, targets)
```

**Train it** — 300 steps on the *unlabeled* pool. Watch the loss fall: the model
is genuinely learning to recognize "same image, different view."

```{python}
encoder = Encoder()
projector = nn.Sequential(nn.Linear(64, 64), nn.ReLU(), nn.Linear(64, 32))
opt = torch.optim.Adam(list(encoder.parameters()) + list(projector.parameters()), lr=1e-3)

_t0 = time.time()
loss_curve = []
for step in range(300):
    xb = X_unlabeled[torch.randint(0, len(X_unlabeled), (256,))]
    z1 = projector(encoder(augment(xb)))
    z2 = projector(encoder(augment(xb)))
    loss = nt_xent(z1, z2)
    opt.zero_grad(); loss.backward(); opt.step()
    if step % 50 == 0:
        loss_curve.append((step, round(loss.item(), 3)))
print("contrastive loss:", loss_curve)
print(f"trained in {time.time() - _t0:.0f}s on CPU  (labels used: 0)")
```

The loss drops from ~6 to ~4 — the contrastive task is being solved. So how good
are the features? Let's measure honestly, using labels **only to evaluate** (never
to train the encoder). We compare three feature spaces with a simple
5-nearest-neighbor classifier:

::: {.callout-important title="🤔 Wait — the fancy method *lost*?"}
On this tiny, CPU-scale setup the honest result is **surprising**: our
contrastively-trained features are barely better than a *randomly initialized*
encoder, and **raw pixels win outright**. That is not a bug — it's the real
lesson.

Fashion-MNIST is small and low-resolution, so raw pixels are *already* fairly
separable, and 300 steps of contrastive training on 6,000 tiny images simply
isn't enough signal to learn features that beat them. Self-supervised methods like
SimCLR only pull ahead when:

- the data is **high-dimensional and complex** (big natural images, genomes,
  audio), where raw inputs are *not* linearly separable;
- you pretrain on **huge unlabeled corpora** for **many epochs** with **large
  batches** (SimCLR used batch sizes of 4096+).

Those three requirements — big data, big batches, long training — are *exactly*
why contrastive pretraining is run on **supercomputers**. This little laptop demo
is honest about its own limits, and in doing so it motivates the rest of the
course: [\[01.4\] Distributed Training](../4-distributed-training/index.qmd) and
[\[02.1\] the Perlmutter lab](../../02-llms/1-parallel-training/index.qmd) are how
you get to the scale where methods like this actually shine.
:::

```{python}
        idx = torch.randperm(len(ds), generator=torch.Generator().manual_seed(seed))[:n]
        return torch.stack([ds[i][0] for i in idx]), torch.tensor([ds[i][1] for i in idx])

    class Encoder(nn.Module):
        def __init__(s, dim=256):
            super().__init__()
            s.net = nn.Sequential(
                nn.Conv2d(3, 64, 3, 2, 1), nn.BatchNorm2d(64), nn.ReLU(),
                nn.Conv2d(64, 128, 3, 2, 1), nn.BatchNorm2d(128), nn.ReLU(),
                nn.Conv2d(128, 256, 3, 2, 1), nn.BatchNorm2d(256), nn.ReLU(),
                nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(256, dim))
        def forward(s, x): return s.net(x)

    aug = T.Compose([T.RandomResizedCrop(32, scale=(0.3, 1.0), antialias=True),
                     T.RandomHorizontalFlip(),
                     T.RandomApply([T.ColorJitter(0.4, 0.4, 0.4, 0.1)], p=0.8),
                     T.RandomGrayscale(p=0.2)])

    def nt_xent(z1, z2, temp=0.2):
        z = F.normalize(torch.cat([z1, z2], 0), dim=1); n = z1.shape[0]
        sim = z @ z.t() / temp; sim.fill_diagonal_(-9e15)
        return F.cross_entropy(sim, (torch.arange(2 * n, device=z.device) + n) % (2 * n))

    Xun, _ = take(tr, 50000, 1); Xun = Xun.to(dev)
    Xte, yte = take(te, 4000, 2); Xte = Xte.to(dev); yte = yte.to(dev)
    enc = Encoder().to(dev)
    proj = nn.Sequential(nn.Linear(256, 256), nn.ReLU(), nn.Linear(256, 128)).to(dev)
    opt = torch.optim.Adam(list(enc.parameters()) + list(proj.parameters()), lr=1e-3)
    for _ in range(2000):
        xb = Xun[torch.randint(0, len(Xun), (1024,), device=dev)]
        loss = nt_xent(proj(enc(aug(xb))), proj(enc(aug(xb))))
        opt.zero_grad(); loss.backward(); opt.step()

    def probe(Xtr, ytr):
        enc.eval()
        with torch.no_grad(): Ztr, Zte = enc(Xtr.to(dev)), enc(Xte)
        clf = nn.Linear(256, 10).to(dev); o = torch.optim.Adam(clf.parameters(), lr=1e-2)
        yt = ytr.to(dev)
        for _ in range(200):
            o.zero_grad(); F.cross_entropy(clf(Ztr), yt).backward(); o.step()
        with torch.no_grad(): return (clf(Zte).argmax(1) == yte).float().mean().item()

    def scratch(Xtr, ytr, ep=60, bs=64):
        e = Encoder().to(dev); h = nn.Linear(256, 10).to(dev)
        o = torch.optim.Adam(list(e.parameters()) + list(h.parameters()), lr=1e-3)
        Xt, yt = Xtr.to(dev), ytr.to(dev); e.train()
        for _ in range(ep):
            p = torch.randperm(len(Xt), device=dev)
            for i in range(0, len(Xt), bs):
                b = p[i:i + bs]
                o.zero_grad(); F.cross_entropy(h(e(Xt[b])), yt[b]).backward(); o.step()
        e.eval()
        with torch.no_grad(): return (h(e(Xte)).argmax(1) == yte).float().mean().item()

    rows = []
    for n in [100, 250, 500, 1000, 5000]:
        Xtr, ytr = take(tr, n, 3)
        rows.append([n, round(scratch(Xtr, ytr), 3), round(probe(Xtr, ytr), 3)])
    return {"device": "cuda", "gpu": torch.cuda.get_device_name(0), "dataset": "CIFAR-10",

            "total_s": round(time.time() - t0, 1)}
```

```{python}
from torch import nn

class Downsampler(nn.Module):
    def __init__(self, in_channels, out_channels, stride=2):
        super(Downsampler, self).__init__()
        self.norm = nn.InstanceNorm2d(in_channels)
        self.downsample = nn.Conv2d(
            in_channels=in_channels, 
            out_channels=out_channels,
            kernel_size = stride,
            stride = stride,
        )

    def forward(self, inputs):
        return self.downsample(self.norm(inputs))


class ConvNextBlock(nn.Module):
    def __init__(self, in_channels):
        super(ConvNextBlock, self).__init__()
        # Depthwise, seperable convolution with a large number of output filters:
        self.conv1 = nn.Conv2d(
            in_channels=in_channels,
            out_channels=in_channels,
            groups=in_channels,
            kernel_size=(7, 7),
            padding='same'
        )
        self.norm = nn.InstanceNorm2d(in_channels)
        self.conv2 = nn.Conv2d(
            in_channels=in_channels,
            out_channels=4*in_channels,
            kernel_size=1
        )
        self.conv3 = nn.Conv2d(
            in_channels=4*in_channels,
            out_channels=in_channels,
            kernel_size=1
        )


    def forward(self, inputs):
        # x = self.conv1(inputs)
        # The normalization layer:
        # x = self.norm(x)
        # x = self.conv2(x)
        # The non-linear activation layer:
        # x = torch.nn.functional.gelu(x)
        # x = self.conv3(x)
        # This makes it a residual network:
        return inputs + self.conv3(
            torch.nn.functional.gelu(
                self.conv2(
                    self.norm(
                        self.conv1(inputs)
                    )
                )
            )
        )


class Classifier(nn.Module):


    def __init__(self, n_initial_filters, n_stages, blocks_per_stage, n_outputs):
        super(Classifier, self).__init__()
        # This is a downsampling convolution that will produce patches of output.
        # This is similar to what vision transformers do to tokenize the images.
        self.stem = nn.Conv2d(in_channels=3,
                                    out_channels=n_initial_filters,
                                    kernel_size=1,
                                    stride=1)
        self.norm1 = nn.InstanceNorm2d(n_initial_filters)

        current_n_filters = n_initial_filters
        self.layers = nn.Sequential()
        for n_blocks in range(n_stages):
            # Add a convnext block series:
            for _ in range(blocks_per_stage):
                self.layers.append(ConvNextBlock(in_channels=current_n_filters))
            # Add a downsampling layer:
            self.layers.append(Downsampler(in_channels=current_n_filters, out_channels=2*current_n_filters))
            # Double the number of filters:
            current_n_filters = 2*current_n_filters
        self.head = nn.Sequential(
            nn.Flatten(),
            nn.LayerNorm(current_n_filters),
            nn.Linear(current_n_filters, n_outputs)
        )

    def forward(self, inputs):
        x = self.stem(inputs)
        # Apply a normalization after the initial patching:
        x = self.norm1(x)
        # Apply the main chunk of the network:
        x = self.layers(x)
        # Normalize and readout:
        x = nn.functional.avg_pool2d(x, x.shape[2:])
        x = self.head(x)
        return x
```

```{python}
def contrastive_loss(first_images, second_images, rank, world_size = 1, temperature=0.1):
        # Each image is represented with k parameters,
        # Assume the batch size is N, so the
        # inputs have shape (N, k)

        # These are pre-distributed shapes:
        N = first_images.shape[0]
        k = first_images.shape[1]


        first_images = first_images / torch.norm(first_images,dim=1).reshape((-1,1))
        second_images = second_images / torch.norm(second_images,dim=1).reshape((-1,1))

        # Take the two tuples, and concatenate them.
        # Then, reshape into Y = (1, 2N, k) and Z = (2N, 1, k)

        c = torch.concat([first_images, second_images], dim=0)

        # Gather all the c up if the world size > 1:
        if world_size > 1:
            gathered_c = torch.distributed.all_gather(tensor=c)
            gathered_c = gathered_c.reshape((-1, first_images.shape[-1]))
        else:
            gathered_c = c

        # Each rank computes only a slice of the global loss matrix, or
        # the memory usage gets out of control.

        # We calculate the dot product between the local and global tensors:
        local_reps = c.reshape((c.shape[0], 1, c.shape[1]))
        all_reps   = gathered_c.reshape((1, gathered_c.shape[0], gathered_c.shape[1]))


        # Assume we have n images per rank, for N global images with N = n * world_size
        # Compute the product of these tensors, which gives shape
        # (2n, 2N, k)
        mat =  local_reps*all_reps

        # We need to compute the function (sim(x,y)) for each element in the 2N sequent.
        # Since the are normalized, we're computing x^T . Y / (||x||*||y||),
        # but the norms are equal to 1.
        # So, summing the matrix over the dim = 0 and dim = 1 computes this for each pair.

        sim = torch.sum(mat, dim=-1) / temperature



        # Now, sim is of shape [2*n, 2*N]

        # This yields a symmetric matrix, diagonal entries equal 1.  Off diagonal are symmetrics and < 1.

        # sim = torch.exp(sim / temperature)
        # Now, for every entry i in C (concat of both batches), the sum of sim[i] - sim[i][i] is the denominator

        device = sim.device

        # Since we have a non-symmetric matrix, need to build a non-symmetric index:
        positive = torch.zeros(sim.shape, device=device)

        # We concatenated all the local examples, and compute symmetric positive pairs
        # So for the first N entries, the index of the positive pair is i + N  (locally)
        # For the second N entries, the index of the positive pair is i - N (locally)
        # with a distributed run, we've squashed all the similarity scores together.
        # to a shape of [2*N, 2*N*Size]
        # Each 2*N by 2*N block is the local positive indexes, all others are negative.
        # That means that the index is shifted by global_rank*2*N

        access_index_x = torch.arange(2*N)
        # For the first N, the y-index is equal to x + 2*N
        # For the second N
        access_index_y = torch.arange(2*N)
        # Shift by +/- N:
        access_index_y[0:N] = access_index_y[0:N] + N
        access_index_y[N:]  = access_index_y[N:] - N

        access_index_y +=  rank * 2*N

        # console.log("access_index_y: ", access_index_y, flush=True)

        positive[access_index_x, access_index_y] = 1

        # For the negative, we invert the positive and have to 0 out the self-index entries
        negative = 1 - positive

        # THESE WORK IF IT'S NOT DISTRIBUTED
        # positive = torch.tile(torch.eye(N, device=device), (2,2))
        # # Unsure if this line is needed?
        # positive = positive - torch.eye(2*N, device=device)
        #
        # negative = - (torch.eye(2*N, device=device) - 1)

        with torch.no_grad():
            # Here, we can compute the top-k metrics for this batch, since we have the global state:
            # We want the top 5 entries but the self-sim is obviously perfect.
            # So take the top 6 and reject the first.
            topk = torch.topk(sim, k=6, dim=-1, sorted=True)

            # Top 1 is just an equality check:
            top1_acc = topk.indices[:,1] == access_index_y.to(topk.indices.device)
            top1_acc = torch.mean(top1_acc.to(torch.float))
          
            # Top 5 is a little more complicated:
            # Compute the index distance to the correct index, abs value:
            top5_acc_dist = torch.abs(topk.indices[:,1:] - access_index_y.to(topk.indices.device).reshape(-1,1))
            # Get the minumum value, and see if it is less than 5:
            min_values, _ = torch.min(top5_acc_dist, dim=-1)
            top5_acc =  min_values < 5.
            # Average over the batch dimension:
            top5_acc = torch.mean(top5_acc.to(torch.float))


        negative_examples = sim * negative
        positive_examples = sim * positive

        # Now, positive/negative examples is the temperature normalized similarity.
        # we need to sum across the whole batch dimension to compute it per-example:


        # Compute the alignment, summed over the entire global batch:
        alignment = torch.sum(positive_examples, dim=-1)

        # Compute the exp, which we'll eventually sum and log:
        exp = torch.sum(torch.exp(negative_examples), dim=-1)

        # console.log("Alignment: ", alignment, flush=True)
        # console.log("exp: ",       exp, flush=True)


        # And compute the logsumexp of the negative examples:
        log_sum_exp = torch.log(exp )


        # Additionally, we can compute the "floor" of the loss at this batch size:
        # floor = torch.log(1.*N) - 1.

        loss_metrics = {
            "alignment"   : torch.mean(alignment),
            "log_sum_exp" : torch.mean(log_sum_exp),
            "top1"        : top1_acc,
            "top5"        : top5_acc,
            # "floor"       : floor,
        }

        loss = torch.mean( - alignment + log_sum_exp)
        return loss, loss_metrics
```

```{python}
def train_one_epoch(dataloader, t1, t2, model, head, loss_fn, optimizer, rank, size, progress_bar):
    model.train()
    head.train()
    for (batch, (X, _)) in enumerate(dataloader):
        # forward pass
        X1 = t1(X); X2 = t2(X)
        pred1 = head(model(X1))
        pred2 = head(model(X2))
        loss, metrics = loss_fn(pred1, pred2, rank, size)

        # console.log(metrics)
        
        # backward pass calculates gradients
        loss.backward()
        
        # take one step with these gradients
        optimizer.step()

        progress_bar.set_postfix(cpu_metrics)
```

```{python}
def validate_one_epoch(dataloader, t1, t2, model, head, loss_fn, rank, size, progress_bar):
    # Validation must NOT update the weights: put everything in eval mode and
    # disable gradients. (This function used to call .backward()/optimizer.step()
    # — that would *train* on the validation set, which defeats the purpose of a
    # held-out set. Validation only measures; it never learns.)
    model.eval()
    head.eval()
    n = 0.
    sum_metrics = None
    with torch.no_grad():
        for (batch, (X, _)) in enumerate(dataloader):
            # forward pass only
            X1 = t1(X); X2 = t2(X)
            pred1 = head(model(X1))
            pred2 = head(model(X2))
            loss, metrics = loss_fn(pred1, pred2, rank, size)

            cpu_metrics = { key : metrics[key].detach().cpu().numpy() for key in metrics.keys()}
            if sum_metrics is None:
                sum_metrics = cpu_metrics
            else:
                for key in sum_metrics.keys():
                    sum_metrics[key] += cpu_metrics[key]
            progress_bar.update()
            n += 1.

    for key in sum_metrics:
        sum_metrics[key] = sum_metrics[key] / n
    return sum_metrics
```

```{python}
#| eval: false
def evaluate(dataloader, model, head, loss_fn, val_bar):
    # Set the model to evaluation mode - some NN pieces behave differently during training
    # Unnecessary in this situation but added for best practices
    model.eval()
    size = len(dataloader)
    num_batches = len(dataloader)
    loss, correct = 0, 0

    # We can save computation and memory by not calculating gradients here - we aren't optimizing 
    with torch.no_grad():
        # loop over all of the batches
        for X, y in dataloader:

            pred = head(model(X))
            loss += loss_fn(pred, y).item()
            # how many are correct in this batch? Tracking for accuracy 
            correct += (pred.argmax(1) == y).type(torch.float).sum().item()
            val_bar.update()
            
    loss /= num_batches
    correct /= (size*batch_size)
    
    accuracy = 100*correct
    return accuracy, loss
```

```{python}
def fine_tune(dataloader, rep_model, head, loss_fn, optimizer, progress_bar):
    head.train()
    model.eval()
    for batch1, (X, Y) in enumerate(dataloader):
        # forward pass
        # Calling detach blocks all gradients into the representation model!
        rep = rep_model(X).detach()
        pred = head(rep)
        loss = loss_fn(pred, Y)
        
        
        # backward pass calculates gradients
        loss.backward()
        
        # take one step with these gradients
        optimizer.step()
        
        # resets the gradients 
        optimizer.zero_grad()

        correct = (pred.argmax(1) == Y).type(torch.float).mean().item()
                    
        # progress_bar.refresh()
        cpu_metrics = {}
        cpu_metrics["acc"] = f"{correct:.2f}"

        progress_bar.set_postfix(cpu_metrics)
```
